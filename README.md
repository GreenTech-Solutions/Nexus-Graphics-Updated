# Nexus-Graphics-Updated

> Fork of Nexus-Graphics by Karu_Kiruna ([mod portal](https://mods.factorio.com/mod/Nexus-Graphics), source in
> [Karu010/Nexus-Extended-Promethium-Endgame](https://github.com/Karu010/Nexus-Extended-Promethium-Endgame)), updated
> for Factorio 2.1 and published as `Nexus-Graphics-Updated`. All credit for the mod goes to Karu_Kiruna.
> It is a stopgap: once the original has a 2.1 release, this fork is deprecated.

Graphics for [Nexus-Updated](https://github.com/GreenTech-Solutions/Nexus-Updated). Nothing to install on its own: it
comes as a dependency of Nexus-Updated.

This repository holds the `Nexus-Graphics` folder of the upstream repository with its history
(`git subtree split --prefix=Nexus-Graphics`); `main` up to the tag `v0.0.8` is upstream as it is.
